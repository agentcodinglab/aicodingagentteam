## 1. 环境准备

| 组件 | 最低版本 | 用途 |
|---|---|---|
| Docker | 24.0 | 容器化运行各组件 |
| Docker Compose | v2.20 | 多容器编排 |

```bash

node --version
git --version
```

```bash

```

## 3. 容器化部署（推荐）

### 3.1 构建镜像

```bash
docker compose -f deploy/compose/docker-compose.yml build
```

### 3.2 启动全部服务

```bash
docker compose -f deploy/compose/docker-compose.yml up -d
```

### 3.3 验证服务状态

```bash
# 查看容器
docker compose -f deploy/compose/docker-compose.yml ps

# 检查 Coordinator 健康
curl http://localhost:8083/.well-known/agent.json

# 预期输出: Agent Card JSON (id/name/role/capabilities)
```

### 3.4 暴露端口说明

| 端口 | 协议 | 用途 |
|---|---|---|
| 8080 | gRPC | TUI 客户端通信 |
| 8081 | MCP | MCP 客户端调用 |
| 8082 | ACP | ACP 客户端调用 |
| 8083 | A2A | Agent 间 / 外部 Agent 互联 |
| 6379 | Redis | A2A 消息总线（内部） |

### 3.5 停止与清理

```bash
# 停止
docker compose -f deploy/compose/docker-compose.yml down

# 清理数据卷（谨慎，会删除工件）
docker compose -f deploy/compose/docker-compose.yml down -v
```

## 4. 单二进制部署（轻量模式）

适合不使用容器的场景，仅启动 Coordinator，宿主 CLI 在本地运行。

```bash
# 编译
go build -o bin/aicodingagentteam ./cmd/aicodingagentteam

# 初始化全局配置
./bin/aicodingagentteam init --global

# 启动 Coordinator（前台）
./bin/aicodingagentteam serve

# 或指定 A2A 总线
AICODINGAGENTTEAM_A2A_BUS=redis://localhost:6379 ./bin/aicodingagentteam serve
```

## 6. 项目初始化与首次运行

### 6.1 初始化项目配置

在用户项目目录下执行：

```bash
aicodingagentteam init
```

生成 `.aicodingagentteamrc` 和 `.aicodingagentteam/` 目录结构：

```
your-project/
├── .aicodingagentteamrc      # 项目配置
└── .aicodingagentteam/
    ├── rules.toml             # 治理规则
    ├── audit/                 # 审计日志
    ├── memory/                # 记忆库
    └── contracts/             # API 契约
```

### 6.2 导入已有存量项目

```bash
aicodingagentteam adopt
```

### 6.3 完整流水线运行（绿场项目）

```bash
# 交互式（TUI）
/run 搭建一个记账 Web 应用，支持多用户和分类统计

# 非交互式（CI/脚本）
aicodingagentteam run "搭建一个记账 Web 应用" --backend codex
```

流程会在 `docs_confirm` 门禁暂停，等待你在 TUI 中评审 PRD/架构文档后输入 `/continue`。

### 6.4 轻量快速编辑

```bash
# TUI
/quick 修复登录按钮在移动端不居中的问题

# CLI
aicodingagentteam quick "修复登录按钮在移动端不居中的问题"
```

### 6.5 质量校验

```bash
# 执行全套质量门禁 + 运行时探针
aicodingagentteam verify --runtime

# 输出合规报告
aicodingagentteam report
```

## 7. 配置自定义

### 7.1 全局配置 `~/.aicodingagentteam/config.toml`

```toml
[default]
backend = "codex"              # 默认宿主 CLI
auto_approve_gates = false     # CI 模式可设 true 跳过人工门禁

[quality]
threshold = 90                 # 质量得分阈值
skip_checks = []

[knowledge]
enabled = true
engine = "hybrid"              # bm25 / hybrid
cloud_embed = false            # 云端向量默认关闭

[memory]
capture = true
recall = true
scope = "project"              # 不跨项目共享
```

### 7.2 治理规则 `.aicodingagentteam/rules.toml`

```toml
[disabled]
clauses = ["ui-emoji-icon"]

[exclusions]
paths = ["src/legacy/**", "**/*.test.ts"]
```

### 7.3 关键环境变量

| 环境变量 | 作用 | 默认值 |
|---|---|---|
| `AICODINGAGENTTEAM_PORT` | Coordinator gRPC 端口 | 8080 |
| `AICODINGAGENTTEAM_BACKEND` | 默认宿主 CLI | codex |
| `AICODINGAGENTTEAM_QUALITY_THRESHOLD` | 质量门得分阈值 | 90 |
| `AICODINGAGENTTEAM_A2A_BUS` | A2A 消息总线地址 | redis://localhost:6379 |
| `AICODINGAGENTTEAM_WORKSPACE` | 工作目录路径 | . |
| `AGENT_ROLE` | Agent 容器角色标识 | — |
| `OPENAI_EMBED_KEY` | 远程 embedding 密钥 | — |
| `AICODINGAGENTTEAM_ALLOW_CLOUD_EMBED` | `=1` 允许云端 embedding | 0 |

> **Windows 注意**：npm/CI 子进程环境下 Go 工具链需要 `LOCALAPPDATA` 环境变量定位 build cache。若缺失会导致 `GOCACHE is not defined` 错误。e2e 脚本已自动补 fallback（ADR-0012）。

## 8. 常用命令速查

```bash
# 项目管理
aicodingagentteam init              # 初始化项目
aicodingagentteam adopt             # 导入存量项目

# 流程执行
aicodingagentteam run "需求" --backend codex   # 完整流水线
aicodingagentteam quick "小修改"                # 轻量编辑
aicodingagentteam continue                     # 继续暂停的任务

# 质量治理
aicodingagentteam verify --runtime             # 质量校验 + 探针
aicodingagentteam report                       # 合规报告
aicodingagentteam ci                           # CI 治理扫描

# 服务模式
aicodingagentteam mcp serve                     # MCP 服务
aicodingagentteam a2a serve                     # A2A 服务
aicodingagentteam acp serve                     # ACP 服务

# 知识与记忆
aicodingagentteam knowledge-manage add ./docs  # 添加知识库
aicodingagentteam memory show                   # 查看记忆
```

## 10. 故障排查

### 10.1 宿主 CLI 鉴权失败

```
ERROR: host=codex auth_status=not_logged_in
```

解决：进入对应宿主容器或本地执行 `codex login` 完成鉴权。AiCodingAgentTeam 不持有密钥，仅查询鉴权状态。

### 10.2 A2A 总线连接失败

```
ERROR: cannot connect to a2a bus redis://a2a-bus:6379
```

解决：

```bash
docker compose -f deploy/compose/docker-compose.yml ps a2a-bus
# 若未启动
docker compose -f deploy/compose/docker-compose.yml up -d a2a-bus
```

### 10.3 任务 park 暂停

评审角色超时或解析失败会标记 `park`，不会伪造成功。

解决：在 TUI 输入 `/continue` 重试，或 `/plan` 查看阻塞节点。

### 10.4 质量门禁不通过

```
quality-gate: score=78 < threshold=90, delivery blocked
```

查看 `.aicodingagentteam/audit/verify.jsonl` 中 `status=fail` 的检查项，修复后重新运行 `/verify`。可临时降低阈值或跳过检查（仅 CI 调试用）：

```toml
[quality]
threshold = 80
skip_checks = ["runtime-probe"]
```

### 10.5 容器资源占用过高

评审角色 Agent 容器默认全部启动。轻量任务可减少 replicas：

```yaml
agent-qa:
  deploy:
    replicas: 0  # 按需启动
```
