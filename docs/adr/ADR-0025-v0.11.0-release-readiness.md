# ADR-0025：v0.11.0 发布就绪分阶段验证

> 日期：2026-09-10
> 状态：Accepted
> 关联：ADR-0016、ADR-0023、ADR-0024

## 背景

`v0.10.0` 已包含插件生态 PoC、多宿主 E2E 和治理门禁，但发布前仍有 GoReleaser 本地验证、插件开发体验、quickstart 命令一致性和 TUI live E2E 缺口。直接打 tag 会把这些风险带入正式 Release。

## 决策

将 v0.11.0 拆为三个可独立验证的阶段：发布配置与 artifact、插件生态深化、文档与 TUI 收尾。每个阶段先写规格/计划，完成测试和构建后再提交；正式 tag 与 GitHub Release 留到所有验收通过后由维护者执行。

## 后果

- 正面：发布风险前置暴露，插件开发路径可复用，文档和真实 TUI 路径保持一致。
- 负面：正式版本发布延后一个验证阶段。
- 后续：所有阶段通过后创建 annotated tag `v0.11.0`，推送 tag 并观察 Release workflow。
