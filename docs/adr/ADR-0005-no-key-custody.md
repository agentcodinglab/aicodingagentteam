# ADR-0005: 不持有 AI 编码 CLI 的密钥

> 状态：已接受
> 日期：2026-09-02

## 背景

AI 编码 CLI 需鉴权才能调用模型 API。需决定密钥由编排平台管理还是各 CLI 自行管理。

## 决策

**AiCodingAgentTeam 不存储、不持有任何 API Key / 凭证。鉴权全部交底层 CLI。**

关键理由：
1. **安全**：平台不成为密钥集中存储，降低攻击面和合规风险
2. **职责清晰**：编排平台负责调度，鉴权是 CLI 的职责
3. **多租户友好**：不同用户可用各自的 CLI 登录态
4. **审计**：平台仅查询 AuthStatus（是否就绪），不触碰凭证

## 后果

- 正面：安全合规风险低，职责边界清晰
- 负面：用户需在各宿主容器内单独完成 CLI 登录，增加部署步骤
- 后续：容器化时各 host-* 容器需挂载 CLI 配置目录（如 ~/.codex/、~/.claude/）
