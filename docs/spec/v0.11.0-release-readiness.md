# 功能：v0.11.0 发布就绪

## 背景与目标

当前主分支已完成方向 A/C/D、插件生态 PoC、多宿主 E2E 和治理门禁修正。`v0.10.0` 已发布，但发布配置、插件体验、quickstart 文档和 TUI 真实 E2E 仍有可验证缺口。本规格为 `v0.11.0` 建立可复现的发布准备闭环，先验证发布产物，再增强插件生态和文档体验。

## 用户故事

- 作为维护者，我希望在打 tag 前得到跨平台二进制、校验和和发布 workflow 的验证结果，以便安全发布。
- 作为插件开发者，我希望获得可编译的 driver 脚手架、可检索的索引和开发指南，以便接入新的宿主 CLI。
- 作为用户，我希望 quickstart 命令和 TUI 真实运行路径一致，以便快速完成首次任务。

## 功能描述

1. 补充发布校验脚本和 `godocgen` CI artifact 路径，支持本地 snapshot/dry-run。
2. 增强插件脚手架、第三个真实示例 driver、远程 marketplace index PoC 和开发指南。
3. 修正 quickstart 命令、补充预期输出和故障排查，并修复 TUI live E2E 的二进制路径与服务清理。
4. 更新发布文档和计划清单；本阶段不创建或推送正式 `v0.11.0` tag。

## 验收标准

- [ ] `go build ./...`、`go vet ./...`、`go test ./...` 全绿。
- [ ] GoReleaser 配置校验和 snapshot 构建成功，生成至少 Linux/Windows 可执行产物与 checksum。
- [ ] `godocgen` 生成 9 语言入口，且 CI artifact 路径存在。
- [ ] `plugin new` 生成可编译 driver；`plugin search/list` 和 marketplace CRUD 测试通过。
- [ ] 插件生态包含至少 3 个可编译示例 driver，并有开发指南。
- [ ] quickstart 命令使用 `bin/aicodingagentteam`，页面构建成功且 9 语言内容可访问。
- [ ] TUI `npm run build`、`npm run test:unit`、`npm run lint` 通过，live E2E 在预置二进制下通过。
- [ ] `CHANGELOG.md`、网站 changelog 和发布清单包含 `v0.11.0` 计划说明。

## 非目标

- 不创建或推送正式 `v0.11.0` tag，不在本阶段发布 GitHub Release。
- 不引入真实 Claude/DSH 执行；继续遵守 ADR-0005。
- 不改变 ACP/MCP/A2A 协议契约或 Coordinator 核心调度行为。

## 依赖与约束

- 前置：方向 A/C/D 已完成，当前基线为 `v0.10.0`。
- GoReleaser 在 CI 中执行；本地未安装时使用官方 action 或安装到临时目录。
- 插件索引默认本地优先，远程 index 仅做可替换接口 PoC，不上传代码或凭证。
- 所有验收失败必须修复根因，不得降低 `docs/CONSTRAINTS.md` 阈值。
