# 计划：v0.11.0 发布就绪

> 关联规格：`docs/spec/v0.11.0-release-readiness.md`

## 目标

在不创建正式 tag 的前提下，完成可复现的发布验证、插件生态增强和 quickstart/TUI 体验收尾。

## 步骤

1. 发布配置审计与 snapshot 验证
   - 完成标准：GoReleaser `check` 与 snapshot 构建成功，产物和 checksum 可检查。
   - 涉及文件：`.goreleaser.yml`、`.github/workflows/release.yml`、`docs/standards/maintenance.md`
2. `godocgen` 发布 artifact 与多语言入口校验
   - 完成标准：9 语言入口生成，workflow 上传 `website/content/docs/api/`。
   - 涉及文件：`.github/workflows/governance.yml`、`internal/godocgen/`
3. 插件脚手架与 marketplace 深化
   - 完成标准：脚手架输出可编译 driver，CRUD/搜索测试覆盖远程 index 接口，新增第三个示例 driver。
   - 涉及文件：`cmd/aicodingagentteam/plugin.go`、`pkg/plugin/`、`pkg/plugin/examples/`
4. 插件开发指南与索引样例
   - 完成标准：指南覆盖注册、发现、安装、升级、卸载和安全约束；索引样例可搜索。
   - 涉及文件：`docs/plugin-development.md`、`.aicodingagentteam/plugins.example.json`
5. quickstart 文档修正
   - 完成标准：命令统一为 `bin/aicodingagentteam`，补充预期输出和故障排查，9 语言构建通过。
   - 涉及文件：`website/app/[locale]/(marketing)/quickstart/page.tsx`、`website/messages/`、`website/content/docs/`
6. TUI live E2E 修复与验证
   - 完成标准：脚本能定位根目录二进制、服务失败时正确清理，并在预置二进制下通过。
   - 涉及文件：`tui/scripts/e2e-live.mjs`、`tui/package.json`
7. 发布文档收口
   - 完成标准：CHANGELOG、网站 changelog 和发布清单记录 v0.11.0 范围与未打 tag 状态。
   - 涉及文件：`CHANGELOG.md`、`website/content/docs/{en,zh}/changelog.md`

## 并行与关键路径

- 可并行：步骤 2、3、5、6。
- 关键路径：步骤 1 → 步骤 7；步骤 3 → 步骤 4。
- 验证检查点：步骤 1/2 后跑 Go 全量测试；步骤 3/4 后跑插件测试；步骤 5/6 后跑网站与 TUI 检查。

## 风险与回滚

- GoReleaser 版本或配置不兼容：使用 CI action 的固定版本，失败时保留 snapshot 产物并修复配置。
- 插件示例引入真实凭证：示例只返回 `AuthStatus`，不持有 API Key。
- quickstart 多语言内容不同步：先修正英文源，再同步 9 语言文案并构建验证。
- TUI E2E 依赖本机二进制：脚本明确报缺少二进制的错误并清理子进程，不静默跳过。
